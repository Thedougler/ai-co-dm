# Sarn's Landing

## Note
A small Crown Islands fishing village where [[Aleksander Malone]] was once set loose in public. The results were ugly enough to change Crown policy: Malone now requires formal heresy confirmation before he sails. Malone still considers the violence righteous judgment.
