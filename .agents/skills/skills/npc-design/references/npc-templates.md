- **Leverage:** What can they grant, deny, expose, or mobilize?
- **Need:** What do they lack or fear losing?

- **Contradiction:** Two true pressures that can collide.
- **Signals:** Visual anchor · repeatable behavior · voice principle · sample line.
- **PC invitation:** One reason to engage; never a forced bond.
- **If ignored:** The NPC’s next action or consequence.

## Common roles

| Role | Brings to play | Typical pressure |
| --- | --- | --- |
| Informant | A lead or missing context | Accuracy, safety, price |
| Gatekeeper | Access to a person/place/resource | Proof, etiquette, time |
| Patron | A job and resources | Terms, reputation, competing duty |
| Rival | A comparable goal | Race, sabotage, reluctant respect |
| Ally | Capability and a perspective | Cost, boundaries, conflicting aim |
| Witness | A contested account | Fear, memory, credibility |
| Foil | A different answer to the PCs’ value | Example, challenge, temptation |
| Faction face | Institutional leverage | Policy versus personal need |
| Hostage/ward | Stakes and vulnerability | Safety, agency, escape |
| Villain/agent | An active opposing plan | Clock, consequence, choice |

## Failure modes

| Failure mode | Repair |
| --- | --- |
| Biography without want | Replace history with a present-tense ask and deadline. |
| Lore mouthpiece | Let the NPC want something, be wrong about something, or refuse a detail. |
| Persuasion as mind control | Define willingness, stakes, and a concession; a check moves position only. |
| DMPC ally | Give the NPC a narrow competence and a reason to defer to player choices. |
| One-note quirk | Add a limit, need, and pressure-choice that can contradict the quirk. |
| Same NPC on every return | Update the activity log; show a cost or changed relationship. |
| Accidental caricature | Use behavior, priorities, and concrete signals; avoid identity as a gag. |
| Secret kept from play | Seed multiple clues and a way to confront or exploit it. |
| Over-prepped incidental | Cut to name, want, signal, and exit. |
